### ⚙️ Backend (PHP & Laravel)
- **PHP**: Versi 8.2
- **Laravel Framework**: Versi 12.x.
- **Laravel Reverb**: Untuk menangani WebSockets server (real-time communication).
- **Spatie Laravel Permission**: Untuk manajemen role dan permission (hak akses pengguna).
- **Spatie Laravel Activitylog**: Untuk mencatat log aktivitas pengguna di dalam aplikasi.
- **Maatwebsite Excel**: Untuk fitur export/import file Excel (dan CSV).
- **Barryvdh Laravel DomPDF**: Untuk meng-generate file PDF.
- **Intervention Image**: Untuk manipulasi gambar (resize, crop, dll).
- **Pest PHP**: Digunakan sebagai framework untuk testing (unit & feature test).

---

### 🎨 Frontend (JavaScript & CSS)
- **Vite**: Sebagai build tool pengganti Laravel Mix yang lebih cepat.
- **Tailwind CSS (v4)**: Framework CSS untuk styling UI.
- **Alpine.js**: Framework JavaScript ringan untuk menangani interaktivitas UI di frontend.
- **Chart.js**: Untuk membuat grafik dan visualisasi data.
- **Laravel Echo & Pusher JS**: Digunakan bersama Laravel Reverb untuk menerima event real-time (seperti notifikasi) di sisi client.
- **Axios**: Untuk melakukan HTTP request (AJAX).
